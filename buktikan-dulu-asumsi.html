Buktikan dulu asumsi

2021-08-10 · Lesson Learned

Ceritanya lagi memporting osticket di tempat klien ke yii2. osticket ini pakai mysql. semua berkas (image, pdf, xls, etc) secara default disimpan dalam database. saya menginginkan di desain baru semua berkas disimpan pada file system. Debat penyimpanan file system vs db kita lanjut pada posting berikutnya.

Osticket secara default memecah berkas ke potongan 512 KB. Misalnya ada berkas ukuran 1 MB. Maka oleh osticket berkas akan dipecah menjadi 2 baris di ost_file_chunk dengan ukuran masing-masing 512 KB. Karena itu ketika dump kita harus group_concat potongan tersebut agar menghasilkan berkas yg utuh. Skrip dump ada disini.

Di dev, skrip dump tersebut sudah berjalan mulus pakai php7.4 dan mariadb 10.3. skrip menghasilkan 700 MB berkas. Sementara server pakai php7.4 dan mysql 5.6. Ketika skrip dijalankan di server, semua berkas yg didump hanya berukuran 1 KB.

Buru-buru adalah perbuatan setan

Karena mysqlnya udah lawas banget. Maka saya berasumsi ini adalah bugs group_concat. Googling dgn kata kunci "group_concat bugs". benar saja muncul entri BUGS di result. lagi-lagi karena ini "versi lawas" maka tanpa memeriksa result saya simpulkan saja asumsi ini benar.

Dari keputusan ini muncul beberapa rencana solusi
1 install dan restore data mysql5.6 ke mysql versi baru di production
2 dump mysql5.6 di dev. upload berkas hasil dump balik ke production
3 analisa waktu download & upload berkas

Setelah merasa desain solusi kok kompleks amat. Akhirnya saya klik result lain dari googling di atas. ternyata problem ini bukan bugs. Default group_concat di versi 5.6 memang hanya 1024 alias 1 KB !

Haha "Bodo dipiara!, kambing dipiara bisa gemuk."

(kasino, pintar-pintar bodo. 1980)

Solusi

cari besar_maksimum_berkas
SELECT file_id, octet_length(GROUP_CONCAT(filedata)) FROM ost_file_chunk ORDER BY 2 desc;

SET @@group_concat_max_len = besar_maksimum_berkas

sat set, semua berkas sekarang terdump sempurna pakai versi 5.6

Hikmah

  • Sabar. Konfirmasi problem. Buktikan asumsi.
  • Wrong assumption -> fool decision.
  • Kalau lelah, istirahat. bukan kerja.
