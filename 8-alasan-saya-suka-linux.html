8 alasan saya suka linux

2015-03-16 · Kehidupan

1. Tancap dan Install Cukup unduh iso distro yang disukai, kopi ke flash disk, tancap dan install.

2. Driver hardware otomatis terdeteksi Pada sistem operasi proprietary, driver hardware umumnya disediakan terpisah. Biasanya dalam bentuk CD, beberapa bahkan harus mencari sendiri URL nya di internet. Anggaplah kita membeli laptop, maka minimal kita harus install driver untuk Motherboard, VGA, WebCam, Wifi Card, Touchpad, dan SoundCard. Pada distro linux sebagian besar hardware dasar yang dibutuhkan untuk segera bekerja telah bisa terkenali dengan baik. Ada juga beberapa yang belum, sehingga butuh usaha lebih. Namun sebagai manusia beradab, hal ini sangatlah wajar.  Gratis kok nuntut yang tidak-tidak.

3. Instalasi yang menyenangkan Hampir sebagian besar distro linux modern telah menyediakan fitur Live Install. Artinya kita bisa mencicipi fitur OS berbarengan dengan proses instalasi. Misalnya sambil install kita bisa browsing, chatting, bahkan bermain game.

4. Repositori Software Yang Kaya Hampir semua distro menyediakan katalog software siap pakai / repositori. Tidak perlu download sana sini untuk bisa bekerja. Cukup arahkan ke repositori tersebut dan : $ apt-get install _nama_software_ Seketika terinstallah aplikasi beserta semua dependensinya.

5. Ada bash Dengan bash kita bisa main sulap. Dari bash kita bisa eksekusi banyak aplikasi berbasis command line. Dari sekedar copy file antar ruangan sampai copy file antar remote komputer di beda negara. Dari sekedar eject cd-rom sampai meluncurkan roket. Semisal:

Cari semua file pada mesin joni di jakarta yang namanya mengandung kata "fals", kopi file tersebut ke mesin iwan di Palo Alto, USA. joni@oi-cabang-jakarta.com:/$ find . -iname "*fals*" -exec scp {} oi@oi-cabang=palo-alto.com:/home/oi/music/iwan-fals \;

Cari semua file yang mengandung kata "title" pada folder /home/brain/project, ganti semua kata yang ditemukan menjadi "judul": $ ag -rl "title" /home/brain/project | xargs sed -i "s/title/judul/g"

Backup foto dari handphone ke desktop. Hemat memori handphone. Skrip berikut bisa ditanam menjadi daemon yg akan dijalankan sesaat setelah kabel data handphone tertancap pada port usb. $ rsync --remove-source-files -zvh /media/smartphone/DCIM/* /home/oi/Pictures/smartphone

Eject CD-ROM, Kalau CD-ROMnya ditutup, buka lagi. Jail banget sih... while true; do eject && sleep `expr $RANDOM % 5` && eject -t; done;

Luncurkan 100 Al-Qassam rocket ke pangkalan militer Tel Aviv pada jam 9.09 waktu setempat. Pasang crontab pada jam 9.09 dengan command `eksekusi bash script yg mengirimkan sinyal ON ke arduino yg telah terpasang relay untuk memicu rocket launcher.`

6. Remote ssh Dengan ssh kita bisa remote ke mesin manapun, dari manapun, dengan sumber daya yang sangat sangat minimal. Cukup install openssh-server dan openssh-client. Berjayalah ummat manusia!. Apa sih.

7. Kode sumber terbuka Bila muncul bugs atau error di aplikasi bisa kita bongkar dan perbaiki sendiri.

8. Komunitas yang baik Kalau ada masalah, tinggal tanya ke forum. Nggak peduli anda siapa, komunitas dengan sepenuh hati akan membantu.

Masih banyak lagi sih sebenernya. Kita cukupkan sampai delapan dulu. Semoga anda terhibur. Main sirkus kali terhibur.
