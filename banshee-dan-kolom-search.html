Banshee Dan Kolom Search

2012-02-15 · Uncategorized

Folder musik di harddisk saya dikategorikan ke dalam folder-folder seperti di bawah ini :

/Music /chrisye /dewa19 /the-mercys /panbers /dsb

Dahulu saat menggunakan amarok, setelah add music library, Untuk menemukembalikan file musik semuanya bisa diselesaikan pada kolom search.  Misalnya cari kata kunci "chrisye", otomatis semua file yg terkait kata chrisye (baik path, title, metadata, dsb) akan muncul di playlist. Sungguh memudahkan.  Namun karena amarok ini berat, ada kali 1 kuintal beratnya, akhirnya saya beralih ke banshee, asik, simple, en ringan.

Ternyata setelah import media library ke banshee, ketik kata kunci "chrisye",  eh gak muncul sama sekali file-nya babah chrisye, padahal semua file sudah diimport. Kutak-katik,klak klik sana sini, ternyata problem ini bisa diselesaikan menggunakan fitur smart playlist pada menu kiri. Tapi apakah setiap mau nyari musik berdasarkan folder harus selalu membuat smart playlist ?

Goglang-gugling lalu ketemu thread ini : http://mail.gnome.org/archives/banshee-list/2010-March/msg00052.html

Ternyata untuk "search by path" di banshee. Harus menggunakan keywords : "path:/"

Contoh untuk  kasus diatas : "path:/chrisye" (baru deh ketemu semua musik babah chrisye)

:tepok-jidad Kenapa ya sama developernya gak dibuat default fitur "search by path" ini :( Demikian sedikit share saya, semoga tips ini nggak "banshee banshee banget"
