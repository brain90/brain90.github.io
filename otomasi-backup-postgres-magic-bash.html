Otomasi Backup Postgres. Magic Bash.

2015-08-27 · Software

Ceritanya DBA lagi sibuk banget. Tiket Hot Standb di stagingEnv belum dieksekusi juga. Hot Standby saya gunakan untuk mendebug bila terjadi kasus di production. Jadi DB di-dump dulu dari production ke staging, habis itu baru dioprek. Klo ngoprek langsung di production jadi kaya benerin wiper mobil, tapi mobilnya lagi ngebut di jalan tol.

Berhubung belum dikerjakan. Tiap ada kasus saya harus berulang kali lakukan kegiatan yang sama. Minimal 6 kegiatan yang harus dilakukan bila muncul bugs di production :

1. ssh dulu ke production
2. dump database production terakhir
3. scp ke staging
4. create database baru di staging
5. deploy database pada langkah tiga ke database pada langkah 4
6. ubah dan arahkan dsn di sisi aplikasi ke database yg telah dideploy pada langkah 5

Sungguh melelahkan. Bisa habis hampir 5 menit. Itu juga kalo bandwidth lagi bener. Kalo ada 10 kasus, berarti kita ngebuang waktu sebanyak 50 menit. Hei, 50 menit itu aset !. Bisa dikonversi buat :

* Renang.
* Nonton podkes Lex Fridman .
* Nonton pertunjukan pemuda tersesat

Agar bisa dapet  50 menit. Sebagai anak baik budi dan tidak sombong. Jagoan lagipula pintar. Mari otomasi pekerjaan ini.  Inti skrip ada di hereStrings "<<<".  Dengan hereStrings kita bisa jalankan command dari tempat di eksekusinya script. Jadi untuk pekerjaan yang harus lintas server cukup sikat sekali saja di satu tempat.

https://gist.github.com/brain90/df5d815ea74932641144

Simpan skrip di sisi staging, jangan lupa berikan akses executable. ex: "/home/brain/dumpProductionLatest.sh". Agar tambah sederhana - buat entri baru di ~/.bash_aliases yang mengarah ke skrip tersebut. ex:

alias dp="./home/brain/dumpProductionLatest.sh"

Selanjutnya bila kasus serupa terjadi, tinggal enter command "dp" saja dari prompt. Tunggu sejenak. Latest database dari production segera live di staging. Dari yang sebelumnya 6 langkah, setelah di-skrip cukup  1 langkah saja. Selesai.

Catatan :
Data yg dirawat hanya belasan MB, pola ini hanya untuk dadakan saja, akan segera deprecated setelah hot standby ready.
