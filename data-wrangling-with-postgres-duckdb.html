Data Wrangling with postgres &amp; duckdb

2025-05-16 · Kehidupan

Ceritanya DB utama adalah postgres. Ada data baru mau masuk. Berserak dalam format csv. dengan kolom dan tipe data yang sangat beragam. Misinya adalah bersihkan semua data ini as fast as possible dengan effort as little as possible. Agar bisa segera ikut main di postgres.

Constraint: kudu bin wajib harus cli based. Agar bila kelak data berubah dinamis bisa tinggal disekrip. Backend kok gui. Amatir.

Algo: 1. Load semua csv ke duckdb table. Gunakan fitur import csv dengan tipe data otomatis.

CREATE TABLE data_1 AS 
SELECT * 
FROM read_csv_auto('data_1.csv');

Mau kolom csv ada 10, 100, 1000, no problemo. read_csv_auto() akan langsung impor semua baris dgn smooth. Kita gak perlu ribet create ddl dan menentukan tipe data apa yg sesuai untuk masing-masing kolom. Klo 3, 5 kolom masih okelah. klo udah ratusan. ya kali. malang. ( lah bekasi )

2. Koneksikan duckdb ke postgres 

install postgres;
load postgres;
ATTACH 'dbname=dbname user=uname host=localhost' AS db (TYPE postgres, SCHEMA 'public');

3. Salin data ke pg. 

-- dump ddl data_1
.output data_1.ddl
.schema data_1
-- sesuaikan tipe data float di data_1.ddl agar bisa masup pg. di duck float pakainya double. di pg kudu numeric. tinggal find replace aja.
-- run ddl di pg
% psql -U uname -h localhost dbname < data_1.ddl
-- salin ke pg
insert into db.data_1 (select * from data_1)

Yg bikin cara ini asik adalah - semua operasi duckdb running di memori, jadi serba sat-set. Klo bersih-bersih di pg repot. pg blm secanggih duck utk urusan ini. Jadi mending doi tau bersih aja. Setelah csv dinyataken sempurna. Tinggal kita mainkan lebih lanjut di pg. Rebes dah !

Format data yg disupport duck macam ragam, gak hanya csv. Bisa file, network protokol, dbms. Apa bae. dar der dor pokoknya. Lebih lanjut sudah termaktub dan terburai di referensi.
